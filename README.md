# Task Manager Rust

![product](public/screenshot1.png)

This task manager runs in the CLI...

## Built With

- Rust
- Cargo

## Setup & Instructions

```bash
# Clone repository to local machine
git clone https://github.com/MDW-94/task_manager_rs.git

# Install dependencies
cargo install

# To run program
cargo run
```
